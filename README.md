# ツイキャス YouTubeシアパ 自動再生

PCブラウザ版ツイキャスで、YouTubeのシアターパーティ開始時に表示される  
「クリックすると動画の再生を開始します」の操作を省き、自動で再生を開始するユーザースクリプトです。

## できること

- PCブラウザでYouTubeシアターパーティを自動再生します
- シアターパーティ終了後、別のYouTube動画が開始された場合にも対応します
- 配信者側の一時停止・再開には余計な介入をしません
- ツイキャス公式映画など、YouTube以外のシアターパーティには介入しません

## 動作確認

以下の環境・操作で確認しています。

- Floorp
- Brave
- ページ再読み込み後の自動再生
- 同一配信内で別のYouTube動画へ切り替え
- 配信者側の一時停止・再開
- 配信開始から時間を空けてからのシアターパーティ開始

※ツイキャスやYouTube側の仕様変更により動作しなくなる可能性があります。

## インストール

1. Violentmonkey または Tampermonkey などのユーザースクリプト管理拡張をインストールします。
2. `TwitCasting-YouTube-Theater-AutoPlay.user.js` を開き、ユーザースクリプトとして登録します。
3. ツイキャスの視聴ページを再読み込みします。

## 使い方

スクリプトを有効にした状態で、PCブラウザからツイキャスの配信を視聴するだけです。

配信者がYouTubeシアターパーティを開始すると、通常は視聴者側で再生ボタンを押す必要がありますが、このスクリプトがYouTubeプレーヤーへ再生命令を送り、自動で再生を開始します。

## 仕組み

ツイキャスのYouTubeシアターパーティでは、YouTube埋め込みプレーヤーに `enablejsapi=1` が設定されています。

このスクリプトはシアターパーティのYouTube iframeを検出し、YouTube IFrame Player APIの `playVideo` コマンドを送信して再生を開始します。
